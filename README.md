# WebToDB

Query Keeper+

Query Keeper+ is a backend-driven web application built using Django and MySQL. It allows users to securely submit, manage, and retrieve queries related to products, with proper authentication and structured data handling.

Features
User authentication (Signup, Login, Logout)
Submit and manage user queries
Product-related interaction handling
Secure data storage using MySQL
Dynamic data rendering using Django
Tech Stack
Backend: Django, Python
Frontend: HTML, CSS, JavaScript
Database: MySQL
Version Control: Git, GitHub

Project Overview
The application enables users to create accounts and log in securely. Once authenticated, users can submit queries related to products. The backend processes requests using Django, stores the data in a MySQL database, and retrieves it when required. The system ensures smooth interaction between frontend and backend components.
